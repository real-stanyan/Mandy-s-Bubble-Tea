State Machine

PHONE_INPUT → send code → OTP_INPUT
OTP_INPUT → verify success + existing user → DASHBOARD
OTP_INPUT → verify success + new user → SIGNUP_NAME
OTP_INPUT → wrong code → OTP_INPUT (show error)
OTP_INPUT → back → PHONE_INPUT
SIGNUP_NAME → submit name → DASHBOARD
AUTO_LOGIN → has deviceToken → check-token → DASHBOARD
AUTO_LOGIN → token invalid → PHONE_INPUT

Key UI Details

  • OTP 输入框：6 个独立方框，自动跳到下一格，支持粘贴整串
  • 重发倒计时：60 秒冷却，倒计时结束后 "Resend Code" 变为可点击
  • 错误状态：输入框变红 + "Invalid code, please try again"
  • Rate limit：同一号码 5 分钟内最多发 3 次，超过显示 "Too many attempts, try later"
  • 按钮文案变化：原来的 "View My Account" 改为 "Send Verification Code"
